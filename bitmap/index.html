About the Bit Interleaving Function

This function maps points from the unit square [0,1]×[0,1] to the unit interval [0,1] by interleaving the binary digits of the input coordinates.

Given: x = 0.x₁x₂x₃x₄... and y = 0.y₁y₂y₃y₄...
Output: z = 0.x₁y₁x₂y₂x₃y₃...

Key Properties:

  • The function creates a fractal-like, self-similar surface
  • It's discontinuous at dyadic rationals (numbers with terminating binary expansions)
  • The mapping is measure-preserving but not one-to-one
  • Related to Morton encoding (Z-order) used in spatial indexing

Visualization Notes: The jagged, step-like patterns you see are characteristic of this function. Try adjusting the resolution and bit precision to see different levels of detail. Higher bit precision gives more accurate representations but may show more discontinuities.
