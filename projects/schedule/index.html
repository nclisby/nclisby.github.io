Daily Schedule

A simple timer that allows you to schedule focused work blocks interspersed with short breaks.

Edit Mode

Fill in your schedule: each row has a Start Time and an optional Activity. Start times are auto-calculated from your chosen work and break lengths, but you can edit them manually — times below will update automatically.

Use the Work and Break dropdowns to set block lengths. Schedules can be saved locally and loaded later, or shared via a link.

Active Mode

Press Start to begin. The timer counts down your current work block, then automatically starts the break. The current activity and next activity are shown below the timer.

Press Edit at any time to return to the schedule. Pressing Start restarts active mode .

Sound

Enable the Sound checkbox to hear a chime when each block transitions.
