|unit square| = |unit interval|

We will demonstrate that the unit square and the unit interval have the same cardinality!

We will do so by defining the bit interleaving function which is almost a bijection from the unit square [0,1)×[0,1) to the unit interval [0,1).

  • Read the definition of the bit interleaving function to understand what it does.
  • Experiment with the 3d surface plot and 2d heatmap to gain intuition into how the function behaves.
  • For further details see the Proof sketch at the bottom of the page.

The bit interleaving function

f(x, y) = interleave(binary(x), binary(y))

This function maps points from the unit square [0,1)×[0,1) to the unit interval [0,1) by interleaving the binary digits of the input coordinates.

Given: x = 0.x1x2x3x4...2 and y = 0.y1y2y3y4...2
Output: z = 0.x1y1x2y2x3y3x4y4...2

Key properties:

  • The function creates a fractal-like, self-similar surface.
  • Observe that each z value in [0,1) is the image of a point (x,y) in [0,1)×[0,1).
  • This map can be used to demonstrate that [0,1)×[0,1) has the same cardinality as [0,1).
  • See the Proof sketch at the bottom of the page for further details.

Proof sketch

  • There are some subtleties in the proof that [0,1)×[0,1) has the same cardinality as [0,1).
  • One issue is due to the equality of some infinite binary expansions that prevent f, as written, from being single valued.
  • For example, in decimal notation we know that 0.5=0.499999999... and 0.75=0.749999999..., while in binary the equivalent statements are that 0.12 = 0.011111111...2 and 0.112 = 0.101111111...2
  • If we are not careful about this then f would have different values depending on the choice of binary expansion for x and y.
  • We can circumvent this non-uniqueness issue if we define the function “binary” to have a consistent definition in the case of dyadic numbers. (Rational numbers whose denominator when expressed in lowest terms is a power of 2.)
  • We can either choose to represent all dyadic numbers as terminating binary expansions (e.g. 0.112), or to represent all dyadic numbers as non-terminating binary expansions (e.g. 0.101111111...2).
  • If we do this then we have a well-defined map from [0,1)×[0,1) into [0,1). That is, f is injective.
  • Note that f is not surjective, as some values in [0,1) cannot occur (such as 0.011010101010...2; why?), and thus f is not a bijection / one-to-one map.
  • As f is injective the cardinality of [0,1) is at least as great as the cardinality of [0,1)×[0,1).
  • We can easily construct a map from [0,1) into [0,1)×[0,1). (How?)
  • Thus the cardinality of [0,1)×[0,1) is at least as great as the cardinality of [0,1).
  • If |A| ≤ |B| and |B| ≤ |A| then |A| = |B| by the Schröder–Bernstein theorem, which shows that a bijection between A and B can be constructed.
  • Thus we see that [0,1)×[0,1) and [0,1) must have the same cardinality!
